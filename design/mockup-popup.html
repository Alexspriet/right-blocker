Rules

  1. One number means one thing: the big counter is blocks made from this browser; the site's shared counter, if shown, is named as such.
  2. The account on screen is always named: name, handle, network. Never a bare handle.
  3. The daily cap (12 by default) is read in one place, today's bar, and the CTA says what it will do ("Démarrer", "Pause", "Reprendre").
  4. Loading is the skeleton of the final layout; nothing pops, the content rises once.
  5. Every state has a card: loading, running, blocked, done, signed out, error on one account, empty list.
  6. No system font: DM Sans and Space Grotesk, bundled with the extension (4 files), since a popup must not depend on Google Fonts.

Open decisions

  • Where the list comes from: the site has no public JSON today; proposed default is our own JSON on a static host, with name, handle, network, category per entry (cost of asking the site's authors: a few days of waiting).
  • Daily cap: the site asks for 3 by hand; the extension can do 12 at a human pace. Proposed default 12, changeable in Settings (cost: one field).
  • Portraits: initials only (no requests to the networks) or the profile picture fetched by the driver when it is on the page (cost: storage of a 44 px thumbnail per handle).
  • Shared counter: declare each block to a server like the site does, or stay local. Proposed: local first; "Partager le compteur" copies a sentence.

What I would not do

  • Show the log in the popup: it belongs in Settings, behind "Journal".
  • Both counters at the same size (site total and local): one hero, one sentence.
